# LocalGPT Studio
Like LocalGPT, yet you need more features? As they say don't settle for less. Welcome to the older brother of LocalGPT, Studio.


## What is it?

GPT Studio has the same features as LocalGPT, and more! For example, image generation, better formatting, md viewer for visualization, and most importantly being able to run bigger and better models without the limits of browsers. Don't worry about not being able to not use the website anymore, you can run and use the same models in Studio with a new update coming soon.
## The use?

I made this project to slowly bring down AI datacenters which used over 1.23 billion gallons (4.66 billion liters) a day in 2025. That's 448.95 billion gallons (1700.9 liters) of water used in a year. With technology evolving rapidly after a while this project may become the new norm because our computers would be so strong that they go well over what the average LLM needs.
